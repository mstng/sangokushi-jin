# 三国志年代記 — 三国から、晋へ。

黄巾の乱（184年）から東晋の終焉（420年）まで、三国志とその後の歴史を12章でたどるインタラクティブ年表です。

- 51人の人物録と12の合戦録を収録
- 人物・合戦・王朝のつながりを相互に行き来しながら読める構成
- 史実と『三国志演義』由来の物語を分けて表示
- 西晋の統一、八王の乱、永嘉の乱、東晋、淝水の戦い、劉裕による宋建国までを収録

公開サイト: <https://sangokushi-jin.masato-nahoo.chatgpt.site>

## ローカルで起動する

Node.js 18以降を用意し、次のコマンドを実行してください。

```bash
npm ci
npm run dev
```

ブラウザーで <http://localhost:5173> を開きます。外部パッケージへの依存はなく、`npm ci` はロックファイルとの整合確認のために実行します。

## 歴史データの出どころ

人物・合戦・年代の情報は、以下の史料と概説を参照して整理しています。本文は原文の逐語訳ではなく、歴史の流れを初学者向けに要約したものです。各章・人物・合戦に対応する参照先は `src/data.js` の `sources` と各項目の `sources` フィールドで確認できます。

### 史実と『三国志演義』の区別

史実の骨格は『三国志』『晋書』『宋書』『資治通鑑』を基準にし、『三国志演義』に由来する逸話や、後世に広まった物語は各章の「史実と演義」欄で分けています。ただし、正史にも編者の立場や後代の注記があり、記載された内容がそのまま研究上確定した事実とは限りません。年代の暦換算、生没年、兵数、地名比定などに異説がある場合は断定を避けています。

## 転載について

既存サイトの記事本文・解説文・画像を転載していません。歴史上の事実を上記史料・概説で確認し、文章は本作品用に独自に要約しています。史料原文の逐語訳でもありません。参照先の本文や画像をこのリポジトリへ複製しておらず、個別の転載許諾を必要とする転載物はありません。

冒頭の `assets/river-battle.webp` は本作品のためにAIで生成した創作イラストです。特定の戦場、人物の容貌、船の形状を史実どおりに再現した資料画像ではありません。

## AI利用の範囲

この作品は、ChatGPT（Astra）を使って制作しました。次の範囲にAI生成・AI支援の内容が含まれます。

- 12章の見出し、要約、出来事の説明、転換点の解説
- 51人の人物紹介（肩書き、リード文、略歴、人物関係）
- 12の合戦解説（背景、展開、結果、影響）
- 王朝・勢力関係の説明
- 史実と『三国志演義』の違いを説明する文章
- UI文言、HTML、CSS、JavaScript
- 冒頭の創作イラスト

歴史情報は参考史料に基づいて構成していますが、紹介文・解説文そのものにはAIが生成した表現が含まれます。研究論文や専門書の代替ではありません。重要な事実は参照先の史料や専門研究で再確認してください。

このサイトは実行時にAI APIを呼びません。表示される文章と画像は、制作時に生成・編集してリポジトリへ保存した静的コンテンツです。
